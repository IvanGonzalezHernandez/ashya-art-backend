# Scripts SQL

Migraciones manuales para aplicar en la base de datos de producción (alwaysdata) cuando una rama con cambios de esquema se despliega. No se ejecutan automáticamente — Ivan las corre a mano.

Convención de nombre: `YYYY-MM-DD_descripcion_corta.sql`, uno por cambio de esquema, en el orden en que deben aplicarse.
